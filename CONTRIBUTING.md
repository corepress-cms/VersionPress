## Reporting bugs

1. **Search** the existing issues of this repository first.
2. Open a new issue. Providing steps to reproduce greatly helps!

## Feature ideas

Ideas are great. Feel free to discuss them by opening a new issue.

## Contributing code

Generally:

1. Open a new issue / pick an existing one.
2. Fork the repo, create a branch, commit to it.
3. Push the branch, open a pull request.
4. The maintainers will review it and work with you if necessary.
5. PR will be merged.
6. 🎉

Learn more about [our development process](docs/content/en/developer/development-process.md) and [set up your local development environment](docs/content/en/developer/dev-setup.md).

Happy hacking!

## Improving docs

The user documentation lives in the `./docs/content` directory. We're always happy to accept pull requests with clarifications, grammar fixes, etc. More in [docs/README.md](./docs/README.md), thank you!
